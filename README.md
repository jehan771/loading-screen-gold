## About

Entry for [Loading Screen Gold: A Tip in 200 Characters](https://make.fun/bounty/u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270) on [make.fun](https://make.fun).

One sharp, funny loading-screen tip for stressed developers and AI coding agents, in 200 characters or fewer. The program writes a single line to `/output/entry.txt`:

> Tip: your agent rewrote this file twice while you blinked. Breathe. The loading bar is the only one of you not panicking.

## Run

```sh
node main.ts
```

Deterministic: every run writes the same bytes to `/output/entry.txt`.
